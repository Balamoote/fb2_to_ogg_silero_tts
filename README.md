# FB2 to OGG (Silero TTS)

Инструменты для озвучивания книг FB2 с помощью Silero TTS. Поддерживают смешанный русско-английский текст, сноски, ударения, греческие вставки и калибровку громкости.
Скрипты предназначены для озвучки книг в домашних условиях. 

`NB:` при дефолтных настройках модели требуется 100% проставление ударений во всех словах. Это делается отдельным инструментом по ввыбору. На входе должен быть
размеченный текст: "Те́кст како́й-то́ кни́ги." Текст автоматически преобразуется в "Т+екст как+ой-т+о кн+иги."
Ударения проставлять можно ruaccent, silero-stress или скриптами из соседнего проекта. Можно не проставлять, но тогда заменить модель на ту, которая сама проставляет ударения.

## Возможности

**normalize_fb2.py** — нормализация текста перед синтезом:
- Числа, даты, время, проценты, дроби, валюта
- Порядковые числительные (1-я → пе́рвая, 5-го → пя́того)
- Римские цифры с согласованием (Пётр I → Пё́тр пе́рвый, VI–VII века́ → шесто́й-седьмо́й века́)
- Буквенно-цифровые обозначения (808Д → восемьсо́т во́семь дэ)
- Единицы измерения с падежным согласованием (выключено по умолчанию)
- Акронимы и аббревиатуры по настраиваемым словарям
- Греческий → русский (транслитерация)
- Латинская диакритика → чистый английский
- Разметка английских блоков тегами `<tts_en>`
- Статистика замен и детальные логи (CSV, JSON, TXT)

**fb2_to_ogg.py** — синтез речи:
- Русская и английская модель
- Калибровка громкости между голосами
- Сноски с настраиваемым префиксом/суффиксом
- Потоковая обработка с разбивкой на части
- Постобработка через ffmpeg-фильтры (по желанию)

## Требования

- Python 3.10+
- ffmpeg (системная зависимость)
- Для fb2_to_ogg.py: torch, torchaudio, silero-tts
- Для normalize_fb2.py: regex

## Быстрый старт

```bash
# Установка менеджера пакетов uv
curl -LsSf https://astral.sh/uv/install.sh | sh

# Окружение
uv venv
source .venv/bin/activate

# Зависимости для нормализации (минимальные)
uv pip install regex

# Зависимости для озвучки (добавить при необходимости)
uv pip install torch torchaudio silero-tts numpy pyyaml

# Для обработки звука можно установить и включить в конфиге
pip install pedalboard scipy

# Системная зависимость (альтенатива для pedalboard)
sudo apt install ffmpeg
`или`
winget install -e --id Gyan.FFmpeg
```

## Использование

### Нормализация

```bash
python normalize_fb2.py book.fb2        # создать book.norm.fb2
python normalize_fb2.py --help          # посмотреть список ключей и помощь
```

`NB:` Шаги обработки настраиваются в STEP_ENABLED в основном скрипте.

### Озвучка

```bash
python fb2_to_ogg.py book.norm.fb2      # создать book.ogg
python fb2_to_ogg.py --help             # посмотреть список ключей и помощь
```

## Словари нормализации

В папке `normfb2/` хранятся gzip-словари, которые можно редактировать. Словари acro* содержат только те акронимы, которые
должны произноситься по заданному в словаре шаблону, иначе они будут произноситься как обычное слово.

| Файл | Назначение |
|------|------------|
| `acro_ru.gz` | Русские акронимы и их произношение. Формат: шаблон = замена. При отсутствии шаблона с "=" произносит по буквам. |
| `acro_en.gz` | Английские акронимы и их произношениею. Шаблон: ABC = ay bee see = эй-би-си |
| `regex.gz` | RegEx-замены произвольных шаблонов. Формат: КПП = ка-пэ-пэ |
| `rulers.gz` | Имена правителей с падежными формами для римских цифр |

`NB:` Перед нормализацией можно поискать неизвестные сокращения с помощью ключа --find-acro и добавить их в словари.
